# Fonts

Self-hosted, latin subset, woff2, as served by Google Fonts. All three are under the SIL Open Font License 1.1 (`OFL.txt`).

- `inter-latin.woff2`: Inter, variable (weights 100 to 900). Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter).
- `space-grotesk-latin.woff2`: Space Grotesk, variable (weights 300 to 700). Copyright 2020 The Space Grotesk Project Authors (https://github.com/floriankarsten/space-grotesk).
- `jetbrains-mono-latin.woff2`: JetBrains Mono, regular. Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono).
